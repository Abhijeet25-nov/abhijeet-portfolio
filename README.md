# Abhijeet Saxena — Portfolio

A responsive personal developer portfolio built with **HTML, CSS, and vanilla JavaScript**.

## Files

```text
abhijeet-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

You can also use the VS Code Live Server extension.

## Deploy on Render (Static Site)

1. Push these files to the root of your GitHub repository.
2. In Render, choose **New + → Static Site**.
3. Connect your `abhijeet-portfolio` GitHub repository.
4. Set the **Branch** to `main` (or your repository's default branch).
5. Set **Build Command** to leave it blank.
6. Set **Publish Directory** to `.`.
7. Create the static site. Render will provide a public `onrender.com` URL.

This is a static website, so it does not need a Python start command or backend server.

## Customize before publishing

- Update the email address in `index.html` if needed.
- Replace the GitHub profile links with individual project repository URLs when available.
- Add your LinkedIn profile URL if you want it displayed.
- Verify education details and project descriptions before sharing publicly.
